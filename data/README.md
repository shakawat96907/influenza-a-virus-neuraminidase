# Curated Sequence Datasets (T1)

- `raw/`: Raw sequence records retrieved from NCBI Virus.
- `processed/`: Quality-controlled, deduplicated, and country-year capped datasets (*N* = 1,456; 754 Asian and 702 non-Asian sequences, 2015–2025):
  - `final_cap20_meta.csv`: Complete accession numbers, strain names, countries, regions, collection dates, and host metadata (Supplementary Table S1).
  - `final_cap20_prot.fasta`: Curated full-length H1N1 NA protein sequences (1,456).
  - `final_cap20_nuc.fasta`: Curated full-length H1N1 NA coding nucleotide sequences (1,456).
